
**السؤال الأول: اكتب الأمر الذي يعرض الملفات المخفية فقط في المجلد الحالي.**

الجواب:
```bash
ls -d .*
```

**السؤال الثاني: ما الفرق بين المسار المطلق (Absolute Path) والمسار النسبي (Relative Path)؟ مثّل لكل منهما.**

الجواب:

- المسار المطلق (Absolute Path): هو المسار الكامل للملف أو المجلد، ويبدأ من المجلد الجذر (Root)، ويرمز له بـ `/`.

مثال:
```bash
/home/user/os_lab/session1
```

- المسار النسبي (Relative Path): هو المسار الذي يحدد موقع الملف أو المجلد بالنسبة إلى المجلد الحالي الذي نعمل فيه.

مثال:
```bash
os_lab/session1
```

الفرق بينهما: المسار المطلق لا يعتمد على موقع المجلد الحالي، بينما المسار النسبي يعتمد عليه.

**السؤال الثالث: أنشئ الشجرة التالية بأقل عدد من الأوامر؟ جرّبه واشرح الناتج.**

المطلوب إنشاء المجلدين:
```text
os_lab/session1/data
os_lab/session1/code
```

الجواب:

نستخدم الأمر التالي:
```bash
mkdir -p os_lab/session1/{data,code}
```

شرح الأمر:
- `mkdir`: لإنشاء المجلدات.
- `-p`: لإنشاء المجلدات الرئيسية تلقائياً إذا لم تكن موجودة.
- `{data,code}`: لإنشاء مجلدي data وcode ضمن session1.

الناتج:
```text
os_lab
└── session1
    ├── data
    └── code
```

**السؤال الرابع: ما الذي يحدث عند تنفيذ الأمر `cd -`؟**

الجواب:

يُستخدم الأمر `cd -` للانتقال إلى المجلد السابق الذي كنت أعمل فيه، ويقوم أيضاً بعرض مساره.

**السؤال الخامس: لماذا يُعَدّ نظام التشغيل «مدير موارد»؟ اذكر مثالاً من تجربتك العملية.**

الجواب:

يُعَدّ نظام التشغيل مدير موارد لأنه يقوم بإدارة موارد الحاسوب وتنظيم استخدامها بين البرامج والمستخدمين، مثل المعالج (CPU) والذاكرة (RAM) وأجهزة الإدخال والإخراج، ويضمن توزيع هذه الموارد بطريقة مناسبة.

مثال عملي: عند تشغيل عدة برامج في الوقت نفسه، مثل المتصفح ومحرر النصوص ومشغل الفيديو، يقوم نظام التشغيل بتوزيع وقت المعالج والذاكرة بينها حتى تعمل البرامج دون أن يتعارض عملها مع بعضها.
